## Overview

このドキュメントサイトは、技術文書やナレッジベースを効率的に管理・共有するために作られました。

## 特徴

### サイドバーナビゲーション

- 左サイドバー：コンテンツの階層構造を表示
- 右サイドバー：現在のページの目次を表示
- ホバーで開く折りたたみ機能搭載

### Markdownサポート

- Markdownで簡単にコンテンツを作成
- コードブロックのシンタックスハイライト
- 画像や表の埋め込みに対応

### レスポンシブデザイン

- デスクトップからモバイルまで対応
- サイドバーの折りたたみ機能で画面スペースを有効活用
- ダークモード対応

## 使い方

1. コンテンツの閲覧
   - 左サイドバーから目的のページを選択
   - 右サイドバーで現在のページ内を移動

2. ナビゲーション
   - サイドバーは折りたたみ可能
   - マウスホバーで自動的に展開
   - メニューボタンで手動での開閉も可能

## カスタマイズ

このドキュメントサイトは以下の技術で構築されています：

- Next.js
- Tailwind CSS
- Markdown
- TypeScript

必要に応じて機能の追加やスタイルの変更が可能です。
