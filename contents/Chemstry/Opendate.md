# Opendata

# 諸言
自分用です。2025年1月23日現在の自分が化学の実験屋さんで、実験屋さんは装置律速なので、この世に存在している実験装置を物性によってソートしたjsonデータ無いかなと思って調べたらデータベースわらわら出てきたので

"まだ探す余地がありますが、特定分野により焦点を当てたニッチなデータベースやAPIを追加でご紹介できます。さらに掘り下げた例を求める場合、特定の用途や材料に関する詳細を教えていただければ、それに応じてピンポイントで調査できます！どの方向で掘り下げるか教えていただけますか？"

って言われるまで列挙させました。

所望のデータベースは無かったので多分創ります：）

世界って意外とOpen化してるんすね。しらないだけで多分もっとあるんだろうし、すげーや。便利なの追加してこ。

# データベース一覧

## [SciFinder（CAS）](https://www.cas.org/solutions/cas-api-services)
- **内容**: CAS（Chemical Abstracts Service）が提供する化学情報データベース。
- **API**: CAS RESTful APIsで化学物質、反応データ、特許情報、文献情報などを検索可能。
- **用途**: 化合物データの検索、物性データの取得、反応データの統合。
- **利用条件**: 有料サービス。

## Springer Materials
- **内容**: 材料物性データを検索・取得可能なデータベース。
- **用途**: 特定の物性（例: 熱伝導率、弾性係数）の検索。
- **利用条件**: 契約が必要。

## [PubChem](https://pubchemdocs.ncbi.nlm.nih.gov/pug-rest)
- **内容**: 米国国立衛生研究所（NIH）が提供する無料の化学データベース。
- **API**: PubChem APIを提供。
- **用途**: 化学構造検索、化学特性データの取得、生物活性情報の検索。
- **利用条件**: 無料。

## NIST（National Institute of Standards and Technology）
- **内容**: 材料や化学物質の物性データを取得可能。
- **API**: NIST Chemistry WebBook
- **用途**: 標準物質データの取得、化学・物理研究。
- **利用条件**: 一部無料。

## [ChemSpider](http://www.chemspider.com/)
- **内容**: 化学物質データ（CAS番号、分子構造、特性など）を提供。
- **API**: ChemSpider APIを提供。
- **用途**: 分子構造検索、類似化合物の検索。
- **利用条件**: 無料版と有料版あり。

## [Materials Project](https://materialsproject.org)
- **内容**: マテリアルデザインや物性データに特化したオープンデータプロジェクト。
- **API**: Materials Project APIを提供。
- **用途**: 結晶構造データの取得、バンドギャップや弾性率などの物性情報を提供。
- **利用条件**: 無料（登録が必要）。

## ICSD (Inorganic Crystal Structure Database)
- **内容**: 無機結晶構造データを網羅。
- **用途**: 新しい材料設計や結晶構造解析。
- **利用条件**: 有料。

## [Cambridge Structural Database (CSD)](https://www.ccdc.cam.ac.uk/)
- **内容**: 有機分子や金属有機フレームワーク（MOF）の結晶構造データを提供。
- **用途**: 化学結合、結晶解析、分子設計。
- **利用条件**: 有料。

## [REAXYS](https://www.reaxys.com/)
- **内容**: 化学反応、化学物質、材料特性データベース。
- **用途**: 医薬品化学、材料科学。
- **利用条件**: 有料。

## [TIBCO Spotfire](https://www.tibco.com/products/tibco-spotfire)
- **内容**: データ可視化と分析ツールで、材料データの視覚化にも対応。
- **用途**: 材料データの統計解析、データドリブンな意思決定。
- **利用条件**: 有料。

## Open Materials Database (OMDB)
- **内容**: 結晶構造と第一原理計算データを提供。
- **用途**: 高スループット計算による材料探索。
- **API**: 公開APIで自由にデータ取得可能。
- **利用条件**: 無料。

## AFlow (Automatic Flow for Materials Discovery)
- **内容**: 高スループット計算を利用した材料データベース。
- **API**: 公開APIあり。
- **用途**: 新材料の発見、データ駆動型研究。
- **利用条件**: 無料。

## ASM Handbooks Online
- **内容**: 材料特性と設計に関する包括的なデータベース。
- **用途**: 材料選定、加工プロセス設計。
- **利用条件**: 有料。

## CES EduPack by Granta (Ansys Materials Information)
- **内容**: 教育と研究向けの材料データベース。
- **用途**: 教育目的での材料選定、製品設計やプロトタイピング。
- **利用条件**: 比較的安価な教育版あり。

## Knovel Materials Data Search
- **内容**: 材料科学と工学に特化したデータベース。
- **用途**: 材料特性に基づく設計、製造プロセスの選択。
- **利用条件**: 有料プラン。

## World Bank Materials Data
- **内容**: 材料や資源利用に関する統計データ。
- **API**: [World Bank API](https://data.worldbank.org/)
- **用途**: 経済分析や産業動向の予測。
- **利用条件**: 無料。

## 3D Materials Data (MPDS)
- **内容**: 3D構造データと対応する物性情報を提供。
- **用途**: 3Dプリンティングや材料工学。
- **利用条件**: 無料プランあり、有料プランで詳細データ。

## Material Data Ecosystem (MDE)
- **内容**: オープンソースデータベースを統合した材料データ検索。
- **用途**: 新素材探索、最適化プロジェクト。
- **利用条件**: 無料プランあり、一部有料。

## Alloy Phase Diagram Database (APDIC)
- **内容**: 金属合金の相図データを中心としたデータベース。
- **用途**: 合金設計、熱処理プロセスの最適化。
- **利用条件**: 有料。

## NOMAD Repository (Novel Materials Discovery)
- **内容**: 材料科学シミュレーションデータのオープンリポジトリ。
- **API**: 公開APIでのデータクエリが可能。
- **用途**: 大規模データ解析、機械学習による材料探索。
- **利用条件**: 無料。

## e-Xstream Engineering (Digimat)
- **内容**: 複合材料のシミュレーションに特化したデータベース。
- **用途**: 複合材料設計、最適化。
- **利用条件**: 有料。

## MatMatch
- **内容**: 材料選定をサポートするオンラインプラットフォーム。
- **用途**: 材料調達、用途探索。
- **利用条件**: 基本機能は無料、一部は有料。

## Thermo-Calc Software
- **内容**: 熱力学計算と材料プロパティデータベース。
- **用途**: 熱処理プロセス設計、合金研究。
- **利用条件**: 有料ライセンスが必要。

## PlasticsEurope Database
- **内容**: プラスチックに特化したデータベースで、材料特性や用途統計が掲載。
- **用途**: プラスチックの産業別用途解析。
- **利用条件**: 無料。

## CIRAD Wood Properties Database
- **内容**: 木材の機械的・物理的特性を収録したデータベース。
- **用途**: 木材の種類ごとの性能比較。
- **利用条件**: 無料。

## Eurostat Material Flow Accounts (MFA)
- **内容**: 欧州連合内の材料フロー（生産、消費、リサイクル）を統計化したデータ。
- **API**: EurostatのRESTful APIを利用可能。
- **用途**: 材料のライフサイクル分析や持続可能性研究。
- **利用条件**: 無料。

## Carbon Atlas
- **内容**: カーボンフットプリントと材料使用に関する統計データ。
- **用途**: サステナビリティ研究、環境影響評価。
- **利用条件**: 基本機能は無料。

## Expanse Materials API
- **内容**: 金属、セラミックス、ポリマーに関する詳細な特性データを提供。
- **用途**: 高度な材料設計やプロセス開発。
- **利用条件**: 有料。

## Material Cloud
- **内容**: 材料科学に特化したオープンリポジトリで、シミュレーションデータや実験データを収録。
- **API**: オープンAPIが提供され、データ検索が可能。
- **用途**: 基礎研究、材料モデリング。
- **利用条件**: 無料（オープンデータ）。

## IEEE Xplore Materials Database
- **内容**: 材料に関する最新の研究論文を提供。
- **API**: 論文データへのアクセスAPIを提供（契約ベース）。
- **用途**: 材料研究の最新動向の調査。
- **利用条件**: 有料ライセンスが必要。

## MatData Library
- **内容**: 材料特性に特化したライブラリ。
- **用途**: 材料選定とプロセス設計。
- **利用条件**: 学術利用は無料、商用利用は有料。

## SciGlass (Scientific Glass Data)
- **内容**: ガラス材料の特性に特化したデータベース。光学特性、熱的性質、機械的特性を収録。
- **用途**: 光学ガラスや特殊用途ガラスの設計。
- **利用条件**: 有料。
- **リンク**: [SciGlass公式サイト](https://www.sciglass.com/)

## Thermopedia
- **内容**: 伝熱、流体力学、熱物性に特化したオンラインデータベース。
- **用途**: 熱交換器設計、伝熱システム解析。
- **利用条件**: 無料。
- **リンク**: [Thermopedia公式サイト](http://www.thermopedia.com/)

## Intermetallics Data Repository
- **内容**: 金属間化合物に特化したデータベース。結晶構造、相安定性、機械特性のデータを提供。
- **用途**: 合金開発、熱処理プロセス最適化。
- **利用条件**: 無料（一部制限あり）。
- **リンク**: [Intermetallics Data Repository公式サイト](https://www.intermetallicsdata.com/)

## BioMaterials Database
- **内容**: 生体材料やバイオメディカル向けのデータベース。生体適合性、力学的特性、分解性などを収録。
- **用途**: 生体材料の設計や選定。
- **利用条件**: 有料（学術利用は割引あり）。
- **リンク**: [BioMaterials Database公式サイト](https://biomaterialsdb.com/)

## AlloyDB by ASM
- **内容**: 合金の相安定性、機械的特性、腐食特性に関する情報を提供。
- **用途**: 合金設計、特定用途の材料開発。
- **利用条件**: 有料。
- **リンク**: [AlloyDB公式サイト](https://www.asminternational.org/alloydb)

## Material Bank
- **内容**: 建築やインテリアデザイン用材料データを収録。サンプル提供や材料選定のサポートを行う。
- **用途**: 建築用材料の選定、インテリア設計。
- **利用条件**: 無料。
- **リンク**: [Material Bank公式サイト](https://www.materialbank.com/)

## MERLIN Database
- **内容**: 放射線にさらされた材料の特性に関するデータベース。
- **用途**: 原子力産業での材料選定。
- **利用条件**: 無料。
- **リンク**: [MERLIN Database公式サイト](https://merlinmaterials.com/)

## Material Properties Open Database (MPOD)
- **内容**: 高度な材料シミュレーションを支援するオープンデータベース。
- **用途**: 高スループット材料計算。
- **利用条件**: 無料。
- **リンク**: [MPOD公式サイト](https://www.materialsproject.org/mpod)

## Additive Manufacturing Database
- **内容**: 3Dプリンティング材料に特化したデータベース。機械的特性、印刷プロセス条件を収録。
- **用途**: 3Dプリンティングプロセスの最適化。
- **利用条件**: 有料。
- **リンク**: [Additive Manufacturing Database公式サイト](https://additivemanufacturingdb.com/)

## Gabi Database
- **内容**: 材料や製品のライフサイクルアセスメント（LCA）データベース。
- **用途**: サステナビリティ評価。
- **利用条件**: 有料。
- **リンク**: [Gabi公式サイト](https://www.gabi-software.com/)
